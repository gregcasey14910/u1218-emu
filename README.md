# u1218 — UNIVAC 1218 emulator

A Python emulator of the US Navy **UNIVAC 1218** (CP-789) computer, following the
same plan as the AN/UYK-7 project (`../UYK7`, github.com/gregcasey14910/uyk7-emu):

1. instruction-level emulation of the full repertoire,
2. a Tkinter front panel with live lamps, switches and register display,
3. a small BASIC compiler that generates 1218 machine code.

## Status

- **CPU**: all 98 instructions of the repertoire card (Format I and II), from PX 2910:
  ones' complement subtractive adder, A = AU:AL, index registers in core (ICR), SR bank
  addressing, overflow / borrow / comparison designators, skip and stop keys, I/O buffers
  with a console printer on channel 7, faults to 00000 / 00200 (AUTO RECOVERY).
  Interrupts are not modelled yet.
- **Main window** (`u1218`): registers, console keys, memory view coloured by BASIC line,
  BASIC editor with Compile & Load, Step BASIC line, Run BASIC, printer output, listing.
- **CPU drawer panel** (`u1218 --panel`, or the Panel button): live lamps for AU AL D X S P,
  F, SEQUENCE, MODE, PHASE; press a lamp to flip a bit.
- **BASIC** (`src/u1218/basic.py`): LET PRINT IF/THEN GOTO GOSUB/RETURN FOR/NEXT END,
  `IF [NOT] KEYn` (skip keys), `STOP n` (stop keys). Strings are not done yet.
- `docs/UNIVAC_1218_Instruction_Table.xlsx` is generated by `tools/export_repertoire.py`.

## Layout

```
src/u1218/
  word.py        18-bit / 36-bit ones' complement helpers
  repertoire.py  the instruction catalog (one entry per instruction)
  isa.py         encode / decode / disassemble, small assembler
  cpu.py         memory, registers, designators, execution
  basic.py       BASIC compiler
  gui.py         main window
  panel.py       CPU drawer control panel
  widgets.py     drawn panel widgets
  cli.py         command line
programs/        BASIC examples
tests/           pytest suite
docs/            manuals, repertoire cards, panel photo and notes
```

## Setup

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e ".[dev]"
pytest
```

## Run

```powershell
u1218                     # main window
u1218 --panel             # main window and the CPU drawer panel
u1218 --basic programs/fibonacci.bas
```
